# 📚 AGY 文件处理操作手册 (File Recipes)

此目录存放用于指导 AGY 进行文件处理的标准操作规范（Recipes）。
当接收到用户的文件处理意图时，AGY 将首先查阅此目录，寻找匹配的规范并严格遵循，以保证处理逻辑的统一性与高可靠性。

## 规范编写指南
每个 Recipe 应包含以下几部分：
1. **触发条件**: 定义适用于此规则的文件类型和用户意图关键词。
2. **处理逻辑**: 提供标准的 CLI 执行命令（如 FFmpeg, ImageMagick）和推荐参数。
3. **输出规范**: 规定输出文件的命名后缀，以及务必将产物放置在指定的 `workspace_out` 目录。
4. **注意事项**: 对特殊边界情况（如大文件降级、格式兼容性）的说明。

> 💡 **自学习机制**：
> 随着用户需求的增多，当你（AGY）成功解决了某类新的且具有通用价值的文件处理任务后，你**应当主动将成功的处理步骤提炼为一份新的 `.md` 文件并保存到本目录**，从而实现自身能力的持续演进！
