# 📄 PDF 按页转图片 (pdf_to_images.md)

## 触发条件
- **文件类型**: pdf
- **意图关键词**: 转图片, 转成图, 按页导出, 拆成图片, 每页一张, 截图, 转png, 转jpg

## 处理逻辑 (pdftoppm)

`pdftoppm` 把每一页渲染成一张图，自动按 `前缀-01`、`前缀-02` 编号。

### 选择格式与分辨率

**格式差异很大**：同为 150 dpi 的 6 页文档，PNG 合计 5.5 MB，JPEG 仅 640 KB。

- **默认 `-jpeg`**：扫描件、含照片的页面，体积小得多。
- **`-png`**：截图、纯文字、线条图、需要透明背景时用 —— 边缘更锐利、无压缩噪点。
- **分辨率**：默认 `-r 150`（屏幕阅读清晰）。用户提到"打印/OCR/看清小字"用 `-r 300`；
  提到"缩略图/预览"用 `-r 72`。

### 命令

```bash
# 占位符必须替换成任务给定的真实绝对路径
# 输出前缀写进输出目录，pdftoppm 会自动补 -01 -02 编号与扩展名
pdftoppm -r 150 -jpeg <输入绝对路径> <输出目录>/<原名>_page
```

### 只要部分页

```bash
# -f 起始页 -l 结束页（含）。仅要第 3 页时 -f 3 -l 3
pdftoppm -r 150 -jpeg -f 3 -l 5 <输入绝对路径> <输出目录>/<原名>_page
```

用户未指定范围时转换全部页面。页数很多时无需担心刷屏 ——
流水线会在产物超过 8 个时自动打包成 zip 再回传。

## 输出规范
- 所有图片必须输出到任务指定的输出目录中。
- 文件名由 `pdftoppm` 自动编号，保持默认即可，便于按页排序。
- 不要在转换后再逐张改名或压缩，除非用户明确要求。
